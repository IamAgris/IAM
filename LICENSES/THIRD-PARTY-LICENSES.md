## Instructions for Contributors

If you include third-party code in a Contribution, you must:

1. Identify the dependency and its licence;
2. Confirm the licence is compatible with the IAM Controlled Community Licence;
3. Add an entry to this register;
4. Obtain written approval from the Licensor if the licence imposes terms incompatible with noncommercial source-available distribution.
