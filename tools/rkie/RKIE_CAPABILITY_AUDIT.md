# RKIE Capability Audit — IAM Repository vs. Frozen Target Scope

**Date:** 27 November 2026  
**Audited working tree:** `D:\AI\project-aura`, branch `testing`, HEAD `ab87b8f624df14603edd633b8192d08c8e78a4cf` (246 changed/untracked entries, 628 candidate files).  
**Method:** Read-only local audit of the working tree — file reads, `git` queries and read-only executions of the Phase 1 search CLI. No files were changed by the audit. GitHub was not used as the source of truth: its index cannot see the substantial uncommitted work in this tree.  
**Scope:** The frozen RKIE target architecture. The six-layer list contains **26 domains**, not 25 (5+5+5+5+4+2). This document is an audit and implementation matrix, not a new feature list.

## Status vocabulary

| Status | Meaning |
|--------|---------|
| **Existing** | Implemented and working |
| **Partial** | Exists but incomplete |
| **Missing** | No implementation found |
| **Improve** | Exists but needs optimisation |
| **Verify** | Implementation exists but has not been adequately tested |

Where a domain contains both working code and untested or incomplete parts, the more conservative status is used and the working part is named explicitly.

## Overall finding

**No domain is wholly Missing and no domain is fully complete.** Every one of the 26 domains has some real implementation or artefact in the repository. The dominant pattern is **Partial** with three recurring problems:

1. **Artefacts exist but drift is unchecked** (OpenAPI snapshot, migrations, infra config, docs).
2. **Deterministic search exists (Phase 1) but deeper structural intelligence does not** (no AST, no call graph, no FTS, no fuzzy search).
3. **Security/governance rules are implemented in runtime policy but not consistently enforced at call sites or verified in CI.**

The correct next step is therefore **completion and verification of existing systems**, not construction of 26 new subsystems.

## Reuse, do not duplicate

- **Repository search/index:** `tools/rkie/` (Phase 1), `ARCHITECTURE_INDEX.md`, `audit_architecture.py`.

- **Resources/releases:** `services/irwm.py`, `adaptive_model_selector.py`, `ai_research/release_gate.py`, `serving_model.py`, `deployment_preflight.py`.

RKIE must remain **independent of the primary model** (Qwen2.5:3B). It should expose a stable deterministic interface that the model may call; it must not move indexing or verification into the model.
